This repository contains the code I wrote during  [Rock the JVM's Spark Essentials with Scala](https://rockthejvm.com/course/spark-essentials)

Contents of the course include the following:

- DataFrames usage and interns
- Reading from various sources and parsing data
- Columns and Expressions
- DataFrames aggregations
- DataFrames joins
- Types
  - Working with basic and advanced Spark Types
  - Managing Nulls
  - Type-Safe processing with DataSets
- Using the Spark SQL Shell and programmatically accessing SparkSQL
- Low-level Spark: RDDs 
- How to read DAGs and Spark UI
- Spark clusters infrastructure and how to deploy applications on them
- A big data project (RQ, data analysis, proposal of improvements on a business model based on data insights)
